📖 使用说明

怎么打开双击本文件，用 Chrome / Edge / Safari 打开即可，全程离线，无需联网、无需安装。
人生总览怎么用「人生」页是你所有想做的事的总仓库，按 Q1 紧急且重要 / Q2 重要不紧急 / Q3 紧急不重要 / Q4 都不 分四格。勾选即完成，完成的留在格子里。只要没点完成，这件事就会自动出现在每一周的四象限里，不需要任何排期动作；点了完成就从所有周消失（历史推进记录仍然保留）。
想在某周集中推进把人生条目拖到右边某一周（或用卡片上的周次下拉选），它就是「聚焦」到那一周：会升级成那一周的周重点（最重要的每天都要推进一点），周视图的逐日推进表里开始算 x/7。一次只聚焦一周，拖到别的周就是改聚焦；在周次里点 × 可以取消聚焦——取消后它仍然每周进行中。
层级关系「人生」是长期（可以放很久、有已完成/未完成），「周」是本周推进（要求最重要的每天推进一点），「记录」是今天。从人生排期 → 每周推进 → 每天记录，四象限在三个层级上是同一套 Q1–Q4，所以一条事从人生到某一天始终归在同一个象限里。
首页能看什么「记录」页最上方是仪表盘：左边本周进度条（每条周重点，今天推进了就点勾，右侧显示 x/7），右边重要 / 紧急四象限。两处都能直接操作，不用切页。
四象限从哪来今日待办已下线，四象限现在完全由「人生」页的条目驱动：人生里还没完成的事，按它自己的 Q1–Q4 显示在首页右上角和周视图里；在人生页改象限即可。点 ✓ 就是完成，完成后自动从所有象限消失。
怎么管一周「周」页写下本周的最重要与次要事项，之后每天回来记进展：最重要的要求每天至少推进一点，次要的一周内有推进就算达标。逐日推进表里点格子即可补记/取消；首页仪表盘与「本周重点 · 今日推进」也能一键勾。
怎么记录在「记录」页选择日期，按「本周与日重点 → 每日打卡 → 记录与复盘」从上往下填，输入后自动保存。日期旁显示「今天」表示正在记今天。
怎么补记换日期在右侧常驻面板里：`◀ / ▶` 翻一天、日期框直接选、`回到今天` 一键返回。选定后整个记录页就切到那一天，随时补记。（宽屏侧栏在右侧一列，窄屏是右下角小卡片。）
保存状态右上角显示「刚刚 / N 分钟前」＋已保存，并会自己走动；一有改动立刻变成醒目的紫色「尚未保存 · 编辑中…」，写完会自动存，也可以点日期栏右边的保存或按 ⌘/Ctrl + S。
每天怎么收工提醒只在右侧那块常驻面板里（不再占用页面正文）：顶部有北京时间、完成度进度环和「今天还有几项没填」，下面逐条列出每一项的完成情况，未填的写「未填」、填一半的显示百分比、已填完的划掉打勾。全部填完会变成绿色「今天全部填完 ✓」。
评分怎么填虚荣心 / 焦虑 / 抑郁是 0–10 分，越小越好，滑杆本身就是绿→黄→红的渐变，数值读数也会跟着变绿变红（10 分最红）。拖滑杆，或点右侧的 − / ＋ 一次调一分（0 分也能选到），点 × 清除。没填显示「—」，选了 0 显示「0」，两者分得清楚。（手机卡片里的「专注度」不是越小越好，所以没做渐变。）
目标与差距「减肥」卡片里有一行 🎯 目标：体重、运动、饮水、睡眠、餐数都能设目标值（默认 70kg / 30min / 1500ml / 7.5h / 3 顿）。体重和餐数是「上限」——越少越好，运动 / 饮水 / 睡眠是「下限」——越多越好。下面每条都有横条显示今日进度，并直接写出差距——例如「80 / 70 kg　还多 10 kg」（超标标红）或「20 / 30 min　还差 10 min」；达标变绿并盖「达标」章。目标属于全局设置，换日期不会丢，也会一起导出备份。
饮食怎么记「减肥」卡片下半部分：填吃了几顿、勾哪几顿刻意剩了饭（早/午/晚/加餐）、以及饱了就停。这些都会进图表和日历。
侧边常驻提醒宽屏：它是页面右侧的一列，随滚动始终可见，不遮挡内容，切标签页也不会让内容跳动；点其中任意一项 → 滚到对应卡片；点左上角圆形箭头可收起/展开。窄屏（<1330px）：自动变成右下角的小悬浮卡片，依旧常驻可见，点箭头可收起成一条把手。
日历 / 热力图「日历」页有 GitHub 式全年热力图（颜色越深当天完成度越高）、每项坚持（连续多少天、累计多少天，连续 7 天开一朵小红花 🌸）、以及月度日历：点某一天直接打开那天的记录（可以马上补记/修改）；只想快速看一眼就点格子右上角的 ⓘ，会在下方展开当天概要而不离开日历。
查看趋势「图表」页可看体重、睡眠、运动、饮水、情绪、习惯完成率、屏幕时间的变化，可切换 7/30/90 天或全部。
历史去哪了原来的「历史」标签页已并入「图表」页底部：同样的筛选、搜索和记录列表，但和趋势图放在一起，点任意一条会跳到日历并选中那一天。
导出到 Excel「导出 CSV」生成的文件可直接用 Excel 打开（已带 UTF-8 BOM，中文不乱码）。
换电脑 / 换浏览器先导出 JSON，在新环境的同一页面点「导入 JSON 备份」，选择「合并」即可。
数据在哪浏览器 localStorage，键名 daily_tracker_v1。文件移动位置不影响数据。
